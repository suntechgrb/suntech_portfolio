## 3. Cibles (personas)

### A. Dirigeant PME / commerce
- Besoin : site qui convertit, boutique en ligne, image pro  
- Douleur : site lent / moche / qui ne ramène personne  
- Message : “Un site clair, pensé pour les clients — devis fixe.”

### B. Fondateur startup
- Besoin : MVP / app / SaaS rapidement  
- Douleur : trop d’agences lentes et chères  
- Message : “De l’idée au produit en 4–8 semaines (MVP).”

### C. Artisan / TPE (Afuxiora)
- Besoin : clients, devis, factures sans admin  
- Douleur : paperasse, outils trop complexes  
- Message : “Pilotez votre activité. Laissez l’admin à l’IA.”

### D. Tech / CTO / lead dev (ArchiNovaX)
- Besoin : démarrer un projet Spring Boot propre  
- Douleur : architecture foireuse, dette technique  
- Message : “De l’idée à l’architecture — projets prêts pour la prod.”

## 5. Ton & style de marque

**Ton :** pro, direct, rassurant, orienté business (pas “startup hype”).  
**Langues :** FR prioritaire sur Insta FR ; EN possible pour posts internationaux ; AR si audience ciblée.

**Do :**
- Parler résultats clients (leads, ventes, gain de temps)
- Phrases courtes
- CTA clair (1 seul CTA par post)
- Montrer le produit / l’écran / le résultat

**Don’t :**
- Promettre des chiffres inventés
- Critiquer nommément des concurrents
- Publier du code illisible pour non-tech
- Multiplier les hashtags spam

**Couleurs (alignées site) :**
- Navy : `#0B1628`
- Orange : `#F97316`
- Jaune accent : `#FBBF24`
- Fonds clairs / dark possibles

**Visuels :**
- Logo SuntechTN + logos produits (ArchiNovaX, Afuxiora)
- Captures d’écran projets (avec accord client si besoin)
- Bandeau / mockups mobile & web
- Format Insta : **4:5** (posts), **9:16** (Reels / Stories)

## 7. Calendrier type (4 semaines)

### Semaine 1 — Qui on est
1. Post présentation : “Studio digital à Paris”  
2. Reel : “Ce qu’on construit en 15 secondes” (web / mobile / SaaS / IA)  
3. Carrousel : 3 garanties (devis fixe · 24 h · Paris)  
4. Story : sondage “Vous avez un projet web ou app ?”

### Semaine 2 — Services
1. Carrousel Développement web  
2. Post Apps mobiles  
3. Reel MVP 4–8 semaines  
4. Story : swipe-up / lien bio devis

### Semaine 3 — Produits
1. ArchiNovaX — tagline + CTA site  
2. Afuxiora — artisans / TPE  
3. Reel démo courte Afuxiora ou ArchiNovaX  
4. Comparatif simple : “Service sur mesure vs produit prêt à l’emploi”

### Semaine 4 — Conversion
1. Post “Comment demander un devis en 2 minutes”  
2. Reel “On répond sous 24 h — voilà comment ça se passe”  
3. Portfolio / cas client (avec permission)  
4. CTA WhatsApp + email contact@suntech-grb.com

**Rythme suggéré :** 3–5 posts / semaine + Stories 4–5 jours / semaine.
